> 測試類型：前端元素、使用者互動、Mock API、導頁行為

---

## [ ] 【前端元素】頁面載入後顯示帳號與密碼輸入欄位
**範例輸入**：渲染 `<Login />` 元件  
**期待輸出**：畫面中存在 id 為 `username` 的輸入欄與 id 為 `password` 的輸入欄

---

## [ ] 【前端元素】頁面載入後顯示登入按鈕
**範例輸入**：渲染 `<Login />` 元件  
**期待輸出**：畫面中存在文字為「登入系統」的提交按鈕

---

## [ ] 【前端元素】頁面載入後不顯示錯誤訊息
**範例輸入**：渲染 `<Login />` 元件，尚未送出表單  
**期待輸出**：畫面中不存在錯誤訊息區塊

---

## [ ] 【使用者互動】使用者輸入帳號與密碼後，輸入欄值應即時更新
**範例輸入**：在 `username` 欄位輸入 `admin`，在 `password` 欄位輸入 `admin123`  
**期待輸出**：兩個欄位的 `value` 分別更新為 `admin` 與 `admin123`

---

## [ ] 【Mock API】登入成功時呼叫 login() 並導向 /dashboard
**範例輸入**：mock `loginApi` 回傳 `{ token: 'abc', name: 'Admin', role: 'admin' }`，填入帳密後送出表單  
**期待輸出**：`login()` 被以正確 user 物件呼叫；`navigate` 被以 `'/dashboard'` 呼叫

---

## [ ] 【Mock API】登入成功後按鈕不再顯示 loading 狀態
**範例輸入**：mock `loginApi` 成功回傳後  
**期待輸出**：按鈕文字不為「登入中...」

---

## [ ] 【Mock API】登入失敗時顯示 API 回傳的錯誤訊息
**範例輸入**：mock `loginApi` 拋出 `Error('帳號或密碼錯誤')`，填入帳密後送出表單  
**期待輸出**：畫面中出現「帳號或密碼錯誤」文字

---

## [ ] 【Mock API】登入失敗時顯示預設錯誤訊息（非 Error 物件）
**範例輸入**：mock `loginApi` reject 非 Error 物件，填入帳密後送出表單  
**期待輸出**：畫面中出現「帳號或密碼錯誤」文字

---

## [ ] 【使用者互動】送出表單時按鈕顯示 loading 狀態
**範例輸入**：mock `loginApi` 為永遠 pending 的 Promise，填入帳密後送出表單  
**期待輸出**：按鈕文字變為「登入中...」且 `disabled` 屬性為 true

---

## [ ] 【使用者互動】登入失敗後錯誤訊息在下次送出前被清除
**範例輸入**：第一次登入失敗顯示錯誤後，再次送出表單（第二次 mock 仍 pending）  
**期待輸出**：重新送出的瞬間，錯誤訊息消失
